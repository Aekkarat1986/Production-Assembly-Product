# 🏭 Production Assembly Process: Cap Comp

ยินดีต้อนรับสู่ระบบแสดงขั้นตอนกระบวนการผลิตและการประกอบชิ้นส่วน (Cap Comp)

---

## 📋 ภาพรวมกระบวนการผลิต (Process Overview)
กระบวนการผลิตชิ้นส่วนประกอบมีขั้นตอนมาตรฐานดังนี้ครับ:

1. **การเตรียมและตรวจสอบวัตถุดิบ (Raw Material Inspection)**
   - ตรวจสอบความถูกต้องและสภาพของชิ้นส่วนก่อนเข้าสู่ไลน์ผลิต
   - คัดแยกชิ้นส่วนที่ชำรุดหรือไม่ได้มาตรฐาน

2. **กระบวนการประกอบชิ้นส่วน (Assembly Process)**
   - ดำเนินการประกอบตามขั้นตอนการทำงานมาตรฐาน (SOP)
   - ขันยึดชิ้นส่วนด้วยเครื่องมือที่กำหนดค่าแรงบิด (Torque) ที่ถูกต้อง

3. **การตรวจสอบคุณภาพ (Quality Control - QC)**
   - ตรวจสอบความเรียบร้อย รอยตำหนิ และขนาดของชิ้นงาน
   - บันทึกข้อมูลการตรวจสอบคุณภาพลงในระบบ

4. **การบรรจุและจัดเก็บ (Packaging & Storage)**
   - บรรจุสินค้าลงในบรรจุภัณฑ์ที่กำหนดเพื่อป้องกันความเสียหาย
   - ติดฉลากรายละเอียดสินค้าและนำส่งเข้าคลังสินค้า
