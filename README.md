1. **Press Process:** ปั๊มขึ้นรูปชิ้นส่วนโลหะและพลาสติก (Outer, Inner, Spring, Separator)
2. **Plating / Stock ชุบ:** ส่งชุบผิวชิ้นงานตามข้อกำหนด (เช่น TEP, BC, TPI, APK, TI ADT) พร้อมบันทึกข้อมูล Lot และผู้ผลิต
